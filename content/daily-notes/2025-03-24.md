#### [[MATH-GU4042|Modern Algebra II]] lecture notes

- Question: Find all integer solutions to $y^2 = x^3 - 2$
- New kinds of rings: [[Euclidean domains]]
	- Notion of size
- “Integral” domain ($ab = 0 \implies$ one of $a, b$ is 0). But the word “integral” is superfluous

>[!example] Definition:
>Let $R$ be any [[Cancellation laws and integral domains|integral domain]]. A **Euclidean norm** on $R$ is a function $N : R \backslash \{ 0\} \to \mathbb Z$ such that:
>- (i) **Non-negative:** For all $r \in R$, we have $N(r) \geq 0$.
>- (ii) **Division algorithm:** For all $a, b \in R \backslash \{ 0\}$, there exist $q, r \in R$ (not necessarily unique) such that $b = aq + r$, and either $r = 0$ or $N(r) \leq N(a)$.
>
>A domain $R$ is a **Euclidean domain** if it has Euclidean norm.

- Examples: integers, norm is abs
	- Degree of a polynomial over a field
	- Any field, $N(a) = 0$, $a = bb^{-1}a$ (what does this mean?)
- Every ED is a PID: see proof that integers are a PID
- Definition: Strong Euclidean norm (stronger condition—why?)
- Proposition: If $R$ has a strong E. norm, then for any element that is not 0 or a unit, can be factored into a product of irreducibles
- Norm defined on the [[Gaussian integers]]; also defined for any **square-free** integer, not just $i$: define by $N (a + b \sqrt d) = |a^2 - db^2|$
	- $i$ is special because it makes it a strong E. domain
- Counterexample: $\mathbb Z [\sqrt 3]$ not even a [[Unique factorization domains|unique factorization domain]], so certainly not a E. domain


>[!abstract] Lemma:
>- (i) If $\alpha \in \mathbb Z[i]$ has $N(\alpha) = p$ for some prime number $p$, then $\alpha$ is [[Factorization on integral domains|irreducible]]. 
>- (ii) If $p$ is a prime number that is *not* irreducible in $\mathbb Z[i]$, then $p=N(\alpha)$ for some $\alpha \in \mathbb Z[i]$.


- Why should we care?—which primes remain irreducible in $\mathbb Z[i]$?

	- Iff p equiv 1 mod 4

	- Theorem: $n = \prod_i p^{a_i}$ is a sum of squares iff $a_i$ is even for the $i$s where $p_i \equiv 3 \mod 4$. 
- Answer: Finding integer solutions to $y^2 = x^3 -2$ by working in $\mathbb Z[\sqrt 2]$, write as $y^2 + 2 = x^3$.
	- $\mathbb Z[\sqrt - 2]$ is a UFD, both sides have to be cubes.
	- If $\gcd(y-\sqrt - 2, y + \sqrt- 2) = 1$, then both of these parts are cubes.
		- $= \gcd(y + \sqrt {-2}, 2 \sqrt{-2}) = 1$, so we now know that this thing is a cube
	- $y + \sqrt {-2} = (a+b\sqrt{-2})^3 = a^3 + 3a^2b\sqrt{-2} + 6ab^3 - 2b^3\sqrt{-2}$
		- = $(a^3 + 6ab^2) + (3a^2b - 2b^3)\sqrt{-2}$
		- $\implies$ $1 = (3a^2-2b) \implies b = 1, \ 3a^2-2=1 \implies a = \pm 1$
	- Plug back in to get $y = a^3-6ab^2 = 1-6 = -5$ or $5$.
	- So can conclude that $\pm 5, \pm 3$ are the only integer solutions!
