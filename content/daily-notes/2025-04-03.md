**Degree of a linear map**

>[!abstract] Theorem
>Let $f_A : S^n \to S^n$ be a linear map defined by 
>$$ 
>x \mapsto \frac{Ax}{|Ax|},
>$$
>where $A$ is an *invertible* $(n + 1) \times (n +1)$ matrix (i.e., $\det A \neq 0$. Then 
>$$ 
>\deg f_A = \frac{\det A}{|\det A|} = \pm 1.
>$$

- Any matrix with det not 1 can be written as the product of finitely many elementary matrices 
	- Identity with one diagonal entry replaced by some nonzero real number
	- Adding a row
- Proof steps
	- Step 0: True for identity
	- Step 1: True for continuous paths $\lambda : I \to GL_{n+1}(A)$, so that $f_{A_0} \simeq f_{A_1}$ if, then can define path-homotopy by $\lambda(t) \cdot x$ scaled by abs, implies the degrees are equal
		- Proved for $x=1$ first
	- Step 2: Prove for $A \in GL_{n+1}(A)$ that can be decomposed into elementary matrices
- Isomorphism $\Delta^n \to D^n$, where $\delta^i \to S^{n-1}$
	- Chain w/ property that boundary zero, can call it a homology class
	- Obtain a particular class in the hom of S^n \cong Z
	- Choosing a clever induced map in homology
	- Infinite group, every element sent to negative except for 0
	- To get the negative set, need to rule out $[c] = 0$, meaning c is not the boundary of an $n + 1$ element
	- Later will prove that c is a generator (choose isomorphism st. the class goes to 1): section on **$\delta$-complexes**

**Chain homotopy**

$$ T_{p-1}(\partial a) + \partial T_p(a) = \psi (a) - \varphi(a) $$
- If they have this relation then they are chain homotopic and induce the same map on homology
	- Start with a class $[a] \in H_p(A_*)$, must have $\partial a = 0$ since it’s just the kernel mod image of previous bdry.
	- Apply $\psi(a)$, which the sum above $+ \psi (a)$
	- But middle term goes away, so $\psi(a) = \varphi(a) + \partial T(a)$, hence classes are equal since they differ by a bdry
- Recall the category with objects top spaces and morphisms that are maps btwn htpy classes ([[Topological categories and functors]]) (so there is one representative $[f]$)
