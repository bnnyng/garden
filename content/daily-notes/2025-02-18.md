- [[Categories and morphisms]]
	- Category (four data): collection, set of morphisms fore each pair, a function beween morphisms, and an identity morphism
	- Axioms: composition is associative, identity


| Category                           | Objects               | Morphisms                                                                           | Identity |     |
| ---------------------------------- | --------------------- | ----------------------------------------------------------------------------------- | -------- | --- |
| $\mathsf {Set}$                    | Sets                  | Functions between sets                                                              |          |     |
| $\mathsf {Grp}$                    | One element $\{ * \}$ | Elements of the group                                                               |          |     |
| Partially ordered sets $(P, \leq)$ | Elements of $P$       | $P(x, y)$ … there is one morphism $\{ * \}$ if $x \leq y$, $\varnothing$ otherwise. |          |     |

- Example
	- Top, objects are pairs, morphisms are continuous maps
	- Group is a category with objects … none $*$, just one sort of element , composition and associative
		- Upshot: Objects of categories don’t necessarily have elements, has 
	- Partially ordered sets $( P , \leq )$. Objects are elemements … not a set with extra structure
