#### [[MATH-GU4053|Algebraic Topology]]

- Important notions from previous courses:
	- [[§ Point-Set Topology]]: compactness, quotient spaces; coming up with a function and explaining that its continuous
	- [[§ Abstract Algebra]]: groups, homomorphisms
- Algebraic topology = “[[Homotopies|homotopy]] theory”
	- Example: homotopic functions on plane w/ origin removed
	- Straight line homotopy is NOT valid; can try this for subspaces of Euclidean spaces in general
- Homotopy equivalence
	- Notation for homotopy equivalence and homotopic are both $\simeq$, but for homotopy equivalence is about a single map—known from context
	- Example: sphere onto the puncture plane (specifically, a deformation retraction) via function that scales each vector to unit length
		- Justifying well-definedness: show that we are never dividing by 0 and always lands in the desired space.
- Tools to DISprove homotopy, homotopy equivalence, contractability (turning topological spaces into algebra):
	- Fundamental groups: input is a top. space + a point, output is a group
	- Cohomology: input is a space, output is an abelian group (infinitely many)
	- Algebra a priori easier
- How to give examples of spaces
	- Subspaces of Euclidean space: $D^n$, $S^n$; some condition w/ subspace topology
	- Quotients, gluing spaces: [[Cell attachments and complexes]] (see Hatcher Ch. 0)
