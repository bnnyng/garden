$\quad$ Current lines of research in **AI ethics**—broadly, work that concerns both AI and ethics—include the following:

| Research direction         | Research goal                                                                                                                                     | Examples and further reading |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| Algorithmic accountability | Be able to explain and/or justify algorithmic decisions                                                                                           |                              |
| Algorithmic transparency   | Openness about the purpose, structure, and actions of algorithms                                                                                  |                              |
| Algorithmic fairness/bias  | Designing algorithms that make fair/unbiased decisions                                                                                            |                              |
| AI for social good         | Ensuring that AI algorithms have a positive impact                                                                                                |                              |
| Responsible AI (RAI)       | The interdisciplinary development of guidelines, laws, regulations, and certifications regarding how AI should be researched, developed, and used |                              |
| Explainable AI (XAI)       | The development and study of automatically generated explanations for algorithmic decisions                                                       |                              |
| Machine behavior           | The interdisciplinary study of machines as a new class of agents with unique behavioral patterns and ecology                                      |                              |
