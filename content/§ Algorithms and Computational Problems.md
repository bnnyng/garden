# Overview

$\quad$ Informally, an **algorithm** is a sequence of well-defined computational steps that takes some values as *input* and transforms them to produce an *output*.

$\quad$ Algorithms can also be viewed as tools for solving well-specified **computational problems**, which are problems defined by a desired relationship between inputs and outputs; the paradigmatic example in computer science is the [[Sorting problems|sorting problem]]. In this case, an algorithm is a particular computational procedure for achieving the specified input-output relationship. An **instance** of a computational problem consists of a particular input (satisfying the constraints imposed in the problem statement) needed to compute a solution to the problem (e.g., a particular sequence of numbers to sort).

$\quad$ **Analysis** of algorithms involves evaluating both *correctness* and *performance*. An algorithm is said to be **correct** if, for every input sequence, it halts with the correct output; a correct algorithm is then said to **solve** the given computational problem.
