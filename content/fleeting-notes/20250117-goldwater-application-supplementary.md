```
Project aim: characterizing serotonin transporter protein (SERT) function using a novel method, inserting purified SERT into lipid membranes to form artifical proteoliposomes, which enables direct observation of drug and environment effects. I was responsible for proteolipsome reconstitution in the wet lab, a day-long procedure involving careful mixing of reagents and manual filtering of the resulting artificial cells. All additional experimentation in the project relied on my proper performance of this procedure. I also performed imaging experiments using a SERT-selective radiotracer. My main empirical contribution was finding amphetamine (AMPH) uptake and subsequent serotonin release in SERT proteoliposomes, with neither in empty liposomes; this suggests AMPH is actively transported into neural cells instead of passively diffusing, and that AMPH has a "reverse uptake" effect on SERT, respectively.

```

Description of research:
```
This original project studies collective mathematical reasoning by examining comments from the first Polymath problem, an online, crowdsourced research effort to develop a new proof of the Hales-Jewett theorem. Starting from scratch, I independently experimented with different analysis methods, meeting with mentors twice weekly to interpret results. Specifically, I coded a custom embedded topic model, with PyTorch neural layers and a hyperbolic embedding option, to represent comments as probability distribution, then applied information-theoretic metrics. Preliminary findings indicate systematic explore-exploit trends in the problem-solving discussion over time. As there are currently few empirical studies of mathematical reasoning, this project contributes to cognitive research generally by giving a uniquely naturalistic approach to studying naturalistic reasoning by quantifying written communication between mathematicians.
```
