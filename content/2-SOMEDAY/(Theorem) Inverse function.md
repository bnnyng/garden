# In higher dimensions

>[!abstract] Theorem: Inverse function
>Suppose $\varphi : U \to \mathbb r^n$ is a $C^k$ (i.e., $k$[[Higher-order derivatives of real functions|-times continuously differentiable]]) map from an open subset $U \subseteq \mathbb R^n$ to $\mathbb R^n$. Suppose further that the [[Derivatives of real functions|derivative]] $d\varphi_{x_0}$ is invertible for some $x_0 \in U$. Then $\varphi$ is invertible in a neighborhood of $x_0$: there exists $\delta > 0$ such that:
>- The image of $\varphi : B(x_0, \delta) \to \mathbb R^n$ is an open set $U’ \subseteq \mathbb R^n$;
>- The restriction of $\varphi$ to $B(x_0, \delta)$ is a bijection with inverse $\psi$;
>- The inverse $\psi$ is also $C^k$.
>
>Then $\varphi$ is “locally invertible” near $x \in \mathbb R^n$ if and only if $d\varphi_x$ is invertible; we can check local invertibility using only derivatives!
