- Cybernetic lego bricks

| Name               | Function                                                                                                                                                                                                                              | Examples                                                            |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Modulator          | Allows one signal to directly modulate another, producing either **positive** (change-reinforcing) or **negative** (change-counteracting) **feedback** when “the flow doing the modulating is also the flow that is being modulated.” | Transistors, vacuum tubes, customs duties, traffic lights, enzymes. |
| <br>Transducer     | Changes one kind of information to another. Grand’s **chemoemitters** change **direct** nerve impulses to **diffuse** chemical signals, and vice versa for **chemoreceptors**.                                                        | Microphones, loudspeakers, car indicators, noses.                   |
| Differentiator     | Compares the present level of a signal with previous levels.                                                                                                                                                                          |                                                                     |
| (Leaky) integrator | Measures the total amount of signal arriving over a period of time.                                                                                                                                                                   |                                                                     |
| Oscillator         |                                                                                                                                                                                                                                       |                                                                     |
