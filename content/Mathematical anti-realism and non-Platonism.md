# Overview

| Name of theory or theorists                             | Description                                                                                                                                                                                                                                                                                                                                                              | Problems                                                                                                                                                                                                                                                                                                               | Further reading          |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| Formalism and finitary mathematics (after Hilbert)      | We can only be sure of a **primitive recursive arithmetic**, i.e., the theory of finite strings of symbols on paper, much weaker than first-order [[Axioms of Peano arithmetic\|Peano arithmetic]]. Any “infinitary” mathematics, such as Cantor’s [[Naive conception of set and Russell's paradox\|set theory]], should **conservatively** extend finitary mathematics. | Requires existence of **symbol types**, but unclear how to ground these independently of their instances. Also, Gödel’s [[Undecidability and incompleteness theorems\|second incompleteness theorem]] showed that it would be impossible to prove the **consistency** of finitary mathematics in finitary mathematics. | [[@1926hilbertInfinite]] |
| Intuitionism or constructivism (after Brouwer, Heyting) | Mathematics involves mental constructions, which are completely dependent on human minds: “mathematics is *real* to the extent that it is a consequence of *possible acts of the mind*.”                                                                                                                                                                                 | Seems like a kind of selective **idealism**, e.g., are electrons mind-independent if they can only be defined using Hilbert spaces?                                                                                                                                                                                    |                          |
| Logicism (after Frege)                                  | ”Mathematics is a part of logic.”                                                                                                                                                                                                                                                                                                                                        | Gödel’s [[Godel's first incompleteness theorem\|first incompleteness theorem]] showed that “any system containing Arithmetic is necessarily **unsaturated** (i.e., it is possible to construct a proposition that is neither provable nor refutable in the system).” ([[@1939croccoMathematical]], 19).                |                          |
| Logical positivism (after Wittgenstein)                 | Logical and mathematical truths are true by virtue of being the *logical consequences* of a “bare behavioristic practice, a form of life”; the truths themselves have no *descriptive content* ([[@1994putnamWhy]]).                                                                                                                                                        | Doesn’t account for the fact that in practice, ”synthetic” results, similar to observations in empirical science, can overthrow or force modification of basic principles (e.g., deriving a contradiction).                                                                                                            |                          |
| If-thenism, after Putnam                                | A typical sentence $S$ of some theory (e.g., set theory) is shorthand for the claim that “necessarily, any concrete system that makes the axioms of set theory true makes $S$ true too” ([[@2020clarke-doaneMorality]]).                                                                                                                                                 |                                                                                                                                                                                                                                                                                                                        |                          |
