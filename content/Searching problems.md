# Overview

>[!definition] Searching problem
>- **Input:** A sequence of $n$ numbers $A = (a_1, a_2, \ldots, a_n)$ and a value $v$.
>- **Output:** An index $i$ such that $v = A[i]$ or a special value $\varnothing$ if $v$ does not appear in $A$.
