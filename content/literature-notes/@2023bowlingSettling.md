# Summary

$\quad$ This analysis fully characterizes the implicit conditions required for the [[Goals and purposes are completely described by maximizing expected cumulative reward, after Sutton (2004)|reward hypothesis]] to hold. First, two different interpretive assumptions are made: “goals and purposes” can be understood as a preference relation on possible (distributions of) outcomes, and a reward function captures these preferences if the ordering over agents induced by value functions matches the ordering induced by agent outcomes. Then given these assumptions, a reward function satisfying the [[The Markov property|Markov property]] exists to capture the preference relation if and only if the relation satisfies the [[The von Neumann–Morgenstern rationality axioms and utility theorem|vNM rationality axioms]] and a fifth axiom called “$\gamma$-temporal indifference.”
