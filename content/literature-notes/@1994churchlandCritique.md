# Key terms

- **Correspondence problem:** the computational problem of “determining which features of the earlier presentation go with which features of the later presentation \[of a moving object or scene]” (30).
- **Relevance problem:** also known as the **credit assignment problem**; the problem of determining which stimulus in the world gets the main “credit” when a certain behavior elicits feedback in the world (i.e., “How does the brain know that synapses to strengthen?”, 30).
