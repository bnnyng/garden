# Key terms

>[!example] Key terms from [[@1982marrVision]]:
>- **Representation** = “a formal system for making explicit certain entities or types of information, together with a specification of how the system does this.”
>	- **Description** = the result of representing a certain entity.
>- **Formal scheme** = “a set of symbols with rules for putting them together”, which are used to represent things.

# Reading notes

## Representation and description

- **Trade-off between efficacy and generalization in formalization:** “Any particular representation makes certain information explicit at the expense of information that is pushed into the background and may be quite hard to recover.”
	- 💭 Assuming [[Natural data forms low-dimensional manifolds in high-dimensional embedding space]], some representations arise more “naturally” than others. (Contrast with example of binary vs. base-10 representations for numbers, which are already themselves abstractions).
