# Key terms

**Rationality, resources, and optimization**

- **Mentalistic rationality:** a set of norms governing “reasonable” mental states and processes; **theoretical rationality** is about what one ought to believe and how one’s beliefs ought to change with experience, while **practical rationality** is about what one ought to do.

# Further reading

- [[@1974griceMethod]]: Introduces the project of **creature construction**, which “sketches ‘an ascending order of psychological types’ such that each successive type is able to solve some fundamental problem that eluded previous agent types in the sequence.” (126)
	- [[@2000bratmanValuing]]: An elaboration on the above.
- [[@2021laiPolicy]]: Introduces the general resource-rational principle of **policy compression**, which uses an information-theoretic measure of cost of different *degrees* of compression. Icard sees this **unification** as an example virtue of resource-rationality: “Their entropic cost term leads to a unified analysis of perseveration, randomness, action chunking, state chunking, and several other phenomena” (101).
