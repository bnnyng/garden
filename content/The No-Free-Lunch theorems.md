The **No Free Lunch theorems** for learning algorithms, presented in [[@1996wolpert]] and [[@1997wolpert]], include the following results:
- For every learning model, there exists a data distribution that it will perform poorly on. Thus, *no completely general-purpose learning algorithm can exist*.
- It is equally likely (i.e., equal weight of targets) that an algorithm has a target where it *performs worse than randomly* as a target where it performs better.
