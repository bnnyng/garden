# Overview

Automated controlled-rearing [studies](https://www.buildingamind.com/aitestbed) have shown that newborn chicks can learn to solve challenging **object perception** tasks even without extensive visual experience with objects (e.g., soon after hatching). Such tasks include object parsing, visual binding, view-invariant object recognition, face recognition, rapid object recognition, action recognition, and object permanence.

Importantly, the studies above performed in Wood’s lab involve raising chicks in an environment with a *single object*, indicating that successful performance is an example of **one-shot learning**.

---
# Empirical results

- **Wood (2013):** During the *training phase* (the first week of life), chicks were exposed to a 3D object from a single viewpoint. During the *test phase* (second week), chicks were tested on their ability to recognize the same object from 12 viewpoints using a **two-alternative forced choice test**. Trials were “correct” when chicks spent a greater proportion of time with the imprinted, familiar object than with an unfamiliar object. Chicks’ accuracy was **79 percent** when object was shown from a familiar view and **69 percent** when shown from novel viewpoints, suggesting that the chicks successfully generated **view-invariant representations** that generalized variations in the object’s appearance.
