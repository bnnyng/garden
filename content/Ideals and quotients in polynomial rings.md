# Overview

By the [[(Theorem) First isomorphism theorem|fundamental theorem for ring homomorphisms]], if $R$ is a [[Algebraic rings|commutative ring with unity]] and $a \in R$ is any element, the kernel of the [[Polynomial evaluation|evaluation homomorphism]] 
$$
\ker \textup{ev}_a = \{ f \in R [x] \ : \ \textup{ev}_a(f) = f(a) = 0 \}
$$ is an ideal in the [[Polynomial rings|polynomial ring]] $R[x]$. 

---
# Evaluation at $0$

- **Kernel of the evaluation at $0$:** The kernel is the set of polynomials with constant term $0$: $$ \ker \textup{ev}_0 = \left \{ \sum_{i=0}^N a_i x^i \ : \ a_0 = 0 \right \} = \{ xg \ : \ g \in R[x] \}. $$The second equality, the **absorbing property**, follows since if $f = xg$ for some $g \in R[x]$, then $f$ has no constant term; conversely, if $f$ has $a_0 = 0$, then explicitly $$ f = \sum_{i=1}^N a_i x^i = x \left ( \sum_{i=1}^Na_i x^{i-1} \right ), $$ where the sum on the right-hand side is another polynomial in $R[x]$.
- **Application of the first isomorphism theorem for rings:** The evaluation homomorphism $\textup{ev}_0: R[x] \to R$ is [[Injectivity, surjectivity, and bijectivity|surjective]] since $\text{ev}_0(a_0) = a_0$ for any constant polynomial $a_0$, which are precisely the elements of $R$. Thus, $$ R[x] / \ker \text{ev}_0 \cong R. $$
- **Principal ideal generated by $x$:** The **principal ideal** generated by $x$ in $R[x]$ is, by definition, the set of all polynomials which are multiples of $x$. Clearly, every element has constant term equal to $0$; conversely, if $f$ is a polynomial with constant term equal to $0$, then $$ f = a_1x + \cdots + a_nx^n = x(a_1 + \cdots + a_nx^{n-1}) \in (x), $$ so we have exactly $(x) = \ker \text{ev}_0$ and $$ R[x] / (x) \cong R .$$
