# Overview

$\quad$ **Reference** is the act of using words to convey the identity of an entity or concept, and is a core [[Conventions are stable but arbitrary solutions to repeated coordination problems, after Lewis (1969)|function]] of language ([[@2021hawkinsPartners]]). In a **reference game**, participants are assigned “speaker” and “listener” roles, then shown a *context* of possible referential targets; on each trial, the speaker produces a *referring expression* that allows the listener to select the intended target object from all objects in the context. ***Repeated* reference games** ask speakers to refer to the same targets multiple times with a single interaction partner.
